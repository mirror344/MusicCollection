## Собственный проект

Тема проекта: Музыкальная коллекция

Главный класс: Song

Почему этот объект нужен программе:
объект нужен программе для создания для создания экземпляра песни

Какие данные хранит объект:

- Название песни
- Имя исполнителя
- Альбом
- Год выхода
- Количество лайков

Какие значения задаются через конструктор:
Название песни, имя исполнителя, альбом, год выхода

Какие значения можно задавать автоматически:
Количество лайков



## Практическая работа №2

### Поведение главного класса

Метод 1: `NewLike()`
Что делает: Добавляет к объекту новый лайк

Метод 2: `ChangeYear(int year_new)`
Что делает: Меняет год выхода песни

Метод 3: `GetInfo()`
Что возвращает: Возвращает информацию об объекте

Почему эти действия относятся именно к этому классу:
эти действия относятся к этому классу так, как они связанны с изменением и возвращением характеристик песни
